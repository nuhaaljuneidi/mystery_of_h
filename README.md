# The Mystery of h

Why the convection coefficient is not a material property. Change the situation and watch h change.

## Live tool

[Open The Mystery of h](https://nuhaaljuneidi.github.io/mystery_of_h/)

## Features

- Controls for fluid velocity, fluid type (air, water, oil), geometry (flat plate, cylinder, sphere), and orientation.
- Flow regime chosen automatically from the Reynolds number.
- Contrasts h with the thermal conductivity k, which can be looked up in a table.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
